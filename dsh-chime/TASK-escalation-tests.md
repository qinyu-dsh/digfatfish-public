## 1. 背景：为什么值得做

`lib/client.js` 里的「响过没人理就升级」（HANDOFF §6，已实现）目前只有 **8 项测试**，全部覆盖纯函数 `buildEscalationPlan`（节奏 / 倍数 / 上限 / 非法输入）。

但**升级链真正容易坏的地方不是计划，是调度与取消**：

| 现在的实现 | 一旦被改错，用户看到的现象 |
|---|---|
| `scheduleEscalation` 重排前清旧定时器 | 定时器累积 → **被连响 3 声**，而且查不出原因 |
| `visibilitychange` 且页面可见 → 取消 | 人明明回到页面了，**它还在追着响** |
| `ctx.effect` 清理里 `cancelEscalation()` | 卸载/热更新后定时器裸跑 → **幽灵响铃，重启才好** |
| 触发瞬间重查总开关 + 静音时段 | 关掉开关后**还响一次**；静音时段被追着响 |
| 新通知武装新链前作废旧链 | 两条链并存 → 一条通知**响两轮** |

这些故障的共同点：**代码不报错、测试不红、只有用户的耳朵遭殃**。而这类改动很容易发生——比如用户哪天说「升级间隔改成 20 秒」，谁改完都不会想到去听三遍。

**目标**：让「取消 / 清理」这些路径也被测试钉住，且测试能在**无浏览器**环境下跑（沿用 `batch.test.mjs` / `escalation.test.mjs` 的手法：从源码抽出函数直接执行）。

## 2. 硬约束（违反即算失败）

1. **零行为变化**：不改变任何用户可见行为（节奏、倍数、上限、取消条件、设置项语义都不许动）。这是一次「加测试 + 必要的最小可测化重构」，不是改功能。
2. **现有 49 项测试必须保持全绿**，且 `node --check lib/client.js` 与 `node --check lib/index.js` 通过。
3. **不碰** HTTP 路由、数据格式、设置项 key（`escalateEnabled` / `escalateDelaySec`）、宿主端（`lib/index.js`）。
4. **新测试必须真的跑那份线上逻辑**，不能测一份复制品。两种可接受的做法：
   - a) 沿用现有手法：从 `lib/client.js` 源码里抽出函数体执行（见 `tests/batch.test.mjs` 的 `extractDecideBatch`、`tests/escalation.test.mjs` 的 `extractPlan`）；
   - b) 把升级链的**调度与取消**抽成独立的纯模块（如 `lib/escalation.js`），依赖注入时间与可见性，`client.js` 只做装配 —— **推荐这种**，因为「取消/清理」涉及定时器与事件，纯模块能测得干净。
     抽模块时注意：`client.js` 是手写 bundle，**不要**引入任何打包步骤、不要 require 平台 seed 表之外的模块（见 HANDOFF §5.2）。
5. 测试**不得污染真实环境**：不禁用、不修改用户的 `~/.dsh`（见 HANDOFF §3 的隔离约定）。

## 3. 要覆盖的用例（验收清单）

每条都要有对应测试；名字用中文，写清「在验证什么规则」，不要只写 `test('works')`。

**调度**
1. 首响后用**首次延迟**武装一次重响（默认 30 s → 30000 ms）
2. 到点触发第一轮：增益倍数为计划里的第一档（×1.3）
3. 一轮结束后**继续排下一轮**，间隔为 +45 s（即相对首响 75 s）
4. 追满计划长度后**自行结束**，不再排下一轮
5. 单条链内**定时器不累积**：重排后旧定时器必须被清掉（用假的定时器工厂断言「同时只有一个 pending」）

**取消（这是重点）**
6. `visibilitychange` 且 `document.hidden === false` → 取消，并记一条「已注意到，升级提醒停止」
7. `pointerdown` → 取消
8. `keydown` → 取消
9. 总开关（`enabled`）关掉 → 取消
10. 升级开关（`escalateEnabled`）关掉 → 取消
11. **新通知到来时作废旧链**：旧链的定时器被清、新链从头开始
12. 取消后**不再有任何重响**（推进假时钟到远超计划时长，断言零次播放）

**清理 / 边界**
13. 卸载（跑 `ctx.effect` 的清理器）时：移除三个事件监听 + 清掉定时器 + 链置空
14. 触发瞬间已进入静音时段 → 不响、记「静音时段，升级提醒就此打住」、链终止
15. 触发瞬间总开关/升级开关已关 → 不响、链终止
16. 计划为空（完成音 / `merged` / 开关关）→ **不武装链**（不排定时器）

**不要重复测的**（已有覆盖，避免冗余）：计划本身的节奏/倍数/上限/非法输入收敛 → `tests/escalation.test.mjs`。
