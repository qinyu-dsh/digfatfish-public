## 1. 背景：现在没有任何一行 UI 代码被测试过

当前 65 项测试覆盖的是**纯逻辑**：判定规则（`rules.js`）、批次决策（`decideBatch`）、SSE 帧、升级链调度（`createEscalation`）、自定义铃声 HTTP。

**设置页那段 JSX（`ChimePanel` 及其组件树，900+ 行里的大头）一行都没被执行过。** 而它包含大量 `h(...)` 嵌套、属性名、闭包引用、`React.useState` / `useRef` / `useEffect` 的使用——这些地方最容易出「拼错属性名 / 引用了不存在的变量 / hooks 用法不当」的错。

**这类错误的杀伤方式很特别**：

> 它**不会**让插件挂掉、**不会**让任何现有测试变红。它只会让设置页在打开的一瞬间 React 抛错 → 整个 slot entry 崩掉 → 用户点开「设置 → 响铃」看到**一片空白**，控制台一行 `slot entry crashed in 'settings.section'`。

平时不动设置页就没事；但只要改它（加个开关、调个 props、换个音色下拉），就可能「改完自测看着没事，用户一打开就白屏」。冒烟测试就是保证**它至少能渲染出来、不抛异常**——不测好不好看、不测样式、不测交互细节。

## 3. 两条腿走路

### 3.1 抽纯逻辑 + 单测（必做，性价比最高）

设置页里真正有规则的部分，抽成**依赖注入的纯函数/工厂**再测（手法同 `createEscalation(deps)`）：

| 待抽目标 | 要测的规则 |
|---|---|
| 静音时段判定 | 跨零点（23:00–07:00）、`from === to` 视为不启用、非法输入、空值 |
| 音色解析 `resolveSound(name)` | 内置名 → 内置文件；自定义名 → 上传落盘的文件名；**名字失效 → 回退 blip 并说明**（不能静默不响） |
| 设置读写与迁移 | localStorage 缺失/损坏 JSON/多出未知字段/**缺字段补默认值**；`volume` 越界收敛 |
| 自定义音色与音色清单合并 `soundOptions()` | 内置四个 + 自定义若干；删除后不再出现；自定义默认 gain=1 |
| 设置项变化对升级链的对账 | 关开关 → 活链立刻取消（这条已有覆盖，别重复） |

### 3.2 UI 冒烟：用**极简 React stub** 渲染组件树（必做，本次新增能力）

思路：让 `lib/client.js` 里的组件工厂**接受注入的 UI 运行器**（默认用真实 `React`，测试时注入 stub）。

Stub 只需要满足：

```js
// 只要能承受组件树的结构与 props，不需要真实渲染
const stubReact = {
  createElement: (type, props, ...children) => ({ type, props, children }),
  Fragment: Symbol('Fragment'),
  useState: (init) => [typeof init === 'function' ? init() : init, () => {}],
  useRef: (init) => ({ current: init }),
  useEffect: () => {},
  useMemo: (fn) => fn(),
  useCallback: (fn) => fn,
}
```

**要完成的断言：**

1. **冒烟**：用一组「正常设置」调用面板组件 → **不抛异常**；返回的树非空；树里能找到关键文案节点（如「响过没人理就升级」「自定义铃声」「音量」）。
2. **边界输入**：`customs` 为空 / 有 3 条 / 音色选中一个已被删除的自定义名 / `volume` 为字符串 `'abc'` / `recent` 为空 / `recent` 有 20 条 → 都不抛异常。
3. **关键元素在**：开关（`aria-checked`）、音量滑杆（`type: 'range'`）、两个音色下拉、上传文件 input（`type: 'file'`）、诊断按钮都在树里。
4. **给测试装牙齿**：断言「把一个必需 prop 去掉会抛异常」——例如故意从设置对象里删掉字段后若组件仍不崩，则说明测试没测到（可在文档里说明你选的具体做法）。

> 若发现组件工厂**无法在不做侵入式改动的情况下注入**，允许把一个最小改法写进交付说明：例如把 `ChimePanel` 改成 `makePanel(React, deps)` 的形式，装配处传真实 React。**改法要小、要可读，并在交付里单独说明。**

## 4. 要覆盖的用例（验收清单）

**纯逻辑（预计 12 条）**

1. 静音时段：常规区间（09:00–17:00）内/外
2. 静音时段：跨零点（23:00–07:00）—— 23:30 在内、06:00 在内、12:00 在外
3. 静音时段：`from === to` 视为不启用；空串/非法值视为不启用
4. `resolveSound`：内置四名各自解析到自己
5. `resolveSound`：自定义名 → 用上传的文件名（可能带 `.mp3`）
6. `resolveSound`：未知名字 → 回退 `blip`，且 hint 里说明「原音色已不可用」
7. `soundOptions`：内置 + 自定义合并，自定义 `gain === 1`
8. 设置读写：localStorage 为空 → 全套默认值
9. 设置读写：JSON 损坏 → 回默认值且不抛
10. 设置读写：未知字段被忽略、缺失字段补默认
11. 设置读写：`volume` 越界（负数 / >1 / 字符串）收敛到合法区间
12. 自定义音色被删除后：`soundOptions` 中不再出现，且若它正被选中则回退内置

**UI 冒烟（预计 6 条）**

13. 正常设置渲染不抛异常，树非空
14. 树里能找到关键设置项文案
15. 边界输入（空 customs、超长 recent、非法 volume、失效音色名）渲染不抛
16. 关键控件都在（开关 / range / 两个下拉 / file input / 诊断按钮）
17. `enabled: false`（总开关关）时的分支渲染不抛
18. 故意破坏一个必需输入会让渲染抛异常（证明冒烟测试有牙齿）
