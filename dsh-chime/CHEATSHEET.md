# dsh-chime 一页速查

> 给使用者（不是开发者）。开发/接手请看 [HANDOFF.md](HANDOFF.md)。

---

## 它什么时候响

| 什么时候 | 声音 | 听感 |
|---|---|---|
| **后台活干完了**（一轮正常收尾） | 舒缓 | C6-E6-G6 上行琶音，2.6 秒 |
| **需要你出面**：agent 问你问题 / 计划等你批准 / 卡住了 / 出错了 | 急促 | A5-E6 三轮连击，0.95 秒 |

**不响的情况**（刻意的）：你自己按的停、被中断、超长自动续跑；子 agent 干活也不单独响（主会话收尾时会一起结束）。

> 设计原则：**宁可少响，不可乱响**。一次误报就会让你把它关掉，所以它只在「真干完了」和「真要你出手」时才响。

## 常用操作（全在「设置 → 响铃」）

| 我想…… | 怎么做 |
|---|---|
| **第一次听不到声音** | 点「**解锁并加载**」一次（浏览器规定：页面收到第一次点击前不准出声） |
| 调音量 | 拖「音量」滑杆（完成音会再轻 20%——舒缓音不该吓人） |
| 换音色 | 「完成时」「需协助时」两个下拉，可各选一种 |
| **用自己的铃声** | 「自定义铃声」→ 上传音频文件（wav/mp3/ogg/m4a/flac/webm，单个 ≤ 8 MiB）→ 上传后出现在上面下拉里 |
| 删掉上传的铃声 | 「自定义铃声」右边的下拉 → 选「删除…」 |
| **别在半夜响** | 填「静音时段」，如 `23:00` 至 `07:00`（支持跨零点；留空 = 全天都响） |
| **响过没人理要更响** | 「没人理就升级」打开；首次延迟默认 30 秒，之后 +45 秒再响一次，音量 ×1.3 / ×1.6 / ×1.9，最多 3 次 |
| 关掉标题闪烁 / 系统弹窗 | 「提醒方式」里的两个开关 |
| 一键验证全链路 | 点「**让宿主发一条测试通知**」（走完整链路：宿主 → 网页 → 响铃） |
| 出问题时查原因 | 点「**看诊断信息**」 |
| 全部关掉 | 页面顶部的大开关 |

## 出问题先看这三处

**① 设置页「音频状态」两个徽章**

| 徽章 | 含义 | 怎么办 |
|---|---|---|
| 未解锁 | 浏览器还没拿到一次交互 | 点旁边的「解锁并加载」 |
| **实时推送已连接** | 一切正常（宿主一有通知立刻到） | — |
| 推送未连接，走轮询兜底 | 长连接断了，会自动重连；这期间延迟可能到 20 秒 | 通常自愈；持续这样就看 ③ |
| 连不上宿主 | 宿主没起来或页面是旧的 | Ctrl+Shift+R 硬刷新 |

**② 「最近的通知」列表**——每条都写明「响了」还是「被浏览器拦下」「静音时段跳过」「已合并」。**这是排查的第一现场**。

**③ 还不行就点「看诊断信息」**，或新开标签页访问：

```
http://127.0.0.1:19387/dsh-chime/status
```

看 `streamClients`（1 = 你的页面在线）、`stats.classified`（插件到底听没听到事件）。

## 你可能遇到的疑问

**「怎么只响了一声，我明明有两条通知？」**
一批通知同时到达（比如你刚从别的窗口切回来）时，它只挑**最急的**响一次，其余记成「已合并」。这是为了防止连环轰炸——列表里能看到合并了几条。

**「声音好小。」**
往上拉音量滑杆；另外确认系统音量与浏览器标签页没被静音（右键标签页 → 取消「静音网站」）。

**「我关掉升级开关了，怎么还响？」**
升级开关只影响「追着重响」，正常的首响照旧。要全停用最上面的大开关。

**「它在我正看着屏幕时闪标题。」**
不会——标题只在**页面不可见**时闪，你切回来会立刻恢复。如果真遇到了，那是 bug，请反馈。

**「手机/别的电脑上会响吗？」**
声音响在**打开着页面的那台机器**上。多设备同时开着，会同时响。

**「DSH 重启后会补响一堆旧铃吗？」**
不会。通知只在宿主内存里留 5 分钟，且超过 2 分钟的不再下发。

**「改了代码要重启吗？」**
你不需要改代码。如果哪天要改：宿主半边（`lib/index.js`）**必须重启 DSHA**；浏览器半边（`lib/client.js`）**硬刷新页面**即可。

## 文件都在哪

| 东西 | 位置 |
|---|---|
| 你上传的铃声 | `$DSH_HOME\dsh-chime\sounds\`（重装插件也不会丢） |
| 插件本体 | `<plugin-directory>` |
| 四种内置铃声源码 | 插件目录 `sounds/*.wav` + `synth_sounds.py`（可改音色重新合成） |
| 试听页（不依赖 DSH） | 插件目录 `sounds/preview.html`（双击打开，验证音箱/系统音量） |
